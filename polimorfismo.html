Polimorfismo

O que e Polimorfismo?

A palavra polimorfismo vem do grego e significa "muitas formas". Em POO, e a capacidade de um objeto ser referenciado de multiplas formas, ou de um mesmo metodo se comportar de maneiras diferentes dependendo do objeto que o chama.

Exemplo: o metodo emitirSom() — um Cachorro late, um Gato mia, um Passaro canta. O mesmo metodo, comportamentos distintos.

Polimorfismo em Tempo de Compilacao (Compile-time)

Tambem chamado de polimorfismo estatico, e resolvido pelo compilador antes da execucao do programa. E implementado por meio do Method Overloading e do Operator Overloading.

Method Overloading - Sobrecarga de Metodo

Ocorre quando uma classe possui varios metodos com o mesmo nome, mas com parametros diferentes. O compilador decide qual versao chamar baseado nos argumentos fornecidos.

class Calculadora {
    int somar(int a, int b) { return a + b; }
    double somar(double a, double b) { return a + b; }
    int somar(int a, int b, int c) { return a + b + c; }
}

Operator Overloading - Sobrecarga de Operador

Permite que operadores como +, -, * tenham comportamentos diferentes dependendo dos operandos. Muito usado em C++ e Python. Em Java, nao e suportado diretamente.

Polimorfismo em Tempo de Execucao (Runtime)

Tambem chamado de polimorfismo dinamico, e resolvido em tempo de execucao. E implementado via Method Overriding.

Method Overriding - Sobrescrita de Metodo

Ocorre quando uma subclasse redefine um metodo que ja existe na superclasse, com o mesmo nome, tipo de retorno e parametros.

class Animal {
    void emitirSom() { System.out.println("Som generico"); }
}

class Cachorro extends Animal {
    @Override
    void emitirSom() { System.out.println("Au au!"); }
}

Beneficios do Polimorfismo

  • Permite escrever codigo mais generico e flexivel.
  • Facilita a extensao do sistema sem alterar o codigo existente.
  • Reduz o uso excessivo de estruturas condicionais.
