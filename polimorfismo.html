Polimorfismo

O que é Polimorfismo?

A palavra polimorfismo vem do grego e significa "muitas formas". Em POO, é a capacidade de um objeto ser referenciado de múltiplas formas, ou de um mesmo método se comportar de maneiras diferentes dependendo do objeto que o chama.

Exemplo: o método emitirSom() — um Cachorro late, um Gato mia, um Pássaro canta. O mesmo método, comportamentos distintos.

Polimorfismo em Tempo de Compilação (Compile-time)

Também chamado de polimorfismo estático, é resolvido pelo compilador antes da execução do programa. É implementado por meio do Method Overloading e do Operator Overloading.

Method Overloading - Sobrecarga de Método

Ocorre quando uma classe possui vários métodos com o mesmo nome, mas com parâmetros diferentes. O compilador decide qual versão chamar baseado nos argumentos fornecidos.

class Calculadora {
    int somar(int a, int b) { return a + b; }
    double somar(double a, double b) { return a + b; }
    int somar(int a, int b, int c) { return a + b + c; }
}

Operator Overloading - Sobrecarga de Operador

Permite que operadores como +, -, * tenham comportamentos diferentes dependendo dos operandos. Muito usado em C++ e Python. Em Java, não é suportado diretamente.

Polimorfismo em Tempo de Execução (Runtime)

Também chamado de polimorfismo dinâmico, é resolvido em tempo de execução. É implementado via Method Overriding.

Method Overriding - Sobrescrita de Método

Ocorre quando uma subclasse redefine um método que já existe na superclasse, com o mesmo nome, tipo de retorno e parâmetros.

class Animal {
    void emitirSom() { System.out.println("Som generico"); }
}

class Cachorro extends Animal {
    @Override
    void emitirSom() { System.out.println("Au au!"); }
}

Benefícios do Polimorfismo

  • Permite escrever código mais genérico e flexível.
  • Facilita a extensão do sistema sem alterar o código existente.
  • Reduz o uso excessivo de estruturas condicionais.
