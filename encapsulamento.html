Encapsulamento

O que e Encapsulamento?

Encapsulamento e o principio de esconder os detalhes internos de uma classe e expor somente o que for necessario para o mundo externo. E como uma capsula que protege o que esta dentro.

Na pratica, os atributos de uma classe sao declarados como private e o acesso a eles e feito por meio de metodos publicos chamados getters e setters.

Data Hiding - Ocultacao de Dados

Data Hiding e a tecnica de impedir que partes externas do programa acessem ou modifiquem os dados internos de um objeto diretamente. Isso evita que um dado seja corrompido acidentalmente e garante que a logica de validacao esteja centralizada dentro da propria classe.

Modificadores de Acesso

Os modificadores de acesso controlam o nivel de visibilidade dos atributos e metodos de uma classe. Os principais sao:

  • Public: O membro pode ser acessado por qualquer outra classe, em qualquer pacote.
  • Private: O membro so pode ser acessado dentro da propria classe onde foi declarado.
  • Protected: O membro pode ser acessado dentro da propria classe e tambem por classes que a herdam.

Exemplo de Codigo

class ContaBancaria {
    private double saldo;

    public double getSaldo() {
        return saldo;
    }

    public void depositar(double valor) {
        if (valor > 0) saldo += valor;
    }
}

Beneficios do Encapsulamento

  • Protege os dados de acessos indevidos.
  • Permite alterar a implementacao interna sem afetar quem usa a classe.
  • Facilita a manutencao e os testes do codigo.
  • Aumenta a seguranca e confiabilidade do sistema.
