Encapsulamento

O que é Encapsulamento?

Encapsulamento é o princípio de esconder os detalhes internos de uma classe e expor somente o que for necessário para o mundo externo. É como uma cápsula que protege o que está dentro.

Na prática, os atributos de uma classe são declarados como private e o acesso a eles é feito por meio de métodos públicos chamados getters e setters.

Data Hiding - Ocultação de Dados

Data Hiding é a técnica de impedir que partes externas do programa acessem ou modifiquem os dados internos de um objeto diretamente. Isso evita que um dado seja corrompido acidentalmente e garante que a lógica de validação esteja centralizada dentro da própria classe.

Modificadores de Acesso

Os modificadores de acesso controlam o nível de visibilidade dos atributos e métodos de uma classe. Os principais são:

  • Public: O membro pode ser acessado por qualquer outra classe, em qualquer pacote.
  • Private: O membro só pode ser acessado dentro da própria classe onde foi declarado.
  • Protected: O membro pode ser acessado dentro da própria classe e também por classes que a herdam.

Exemplo de Código

class ContaBancaria {
    private double saldo;

    public double getSaldo() {
        return saldo;
    }

    public void depositar(double valor) {
        if (valor > 0) saldo += valor;
    }
}

Benefícios do Encapsulamento

  • Protege os dados de acessos indevidos.
  • Permite alterar a implementação interna sem afetar quem usa a classe.
  • Facilita a manutenção e os testes do código.
  • Aumenta a segurança e confiabilidade do sistema.
