Abstracao

O que e Abstracao?

Abstracao e o processo de identificar as caracteristicas essenciais de um objeto e ignorar os detalhes irrelevantes para o contexto. E pensar em "o que um objeto faz" sem se preocupar com "como ele faz".

Exemplo classico: ao dirigir um carro, voce usa o volante, o acelerador e o freio. Voce nao precisa saber como o motor funciona internamente — essa complexidade esta abstraida.

Classes Abstratas (Abstract Classes)

Uma classe abstrata e uma classe que nao pode ser instanciada diretamente. Ela serve como modelo base para outras classes. Pode conter metodos concretos (com implementacao) e metodos abstratos (sem implementacao).

abstract class Forma {
    abstract double calcularArea();

    void exibir() {
        System.out.println("Sou uma forma geometrica");
    }
}

class Circulo extends Forma {
    double raio;

    double calcularArea() {
        return Math.PI * raio * raio;
    }
}

Interfaces

Uma interface e um contrato que define quais metodos uma classe deve implementar, sem dizer como. Toda classe que assina uma interface garante que vai fornecer aqueles comportamentos.

interface Voador {
    void voar();
}

class Passaro implements Voador {
    public void voar() {
        System.out.println("O passaro bate asas e voa!");
    }
}

class Aviao implements Voador {
    public void voar() {
        System.out.println("O aviao usa motores e voa!");
    }
}

Ocultacao de Complexidade (Hide Complexity)

Um dos principais objetivos da abstracao e ocultar a complexidade do sistema do usuario final. Ao usar uma classe ou chamar um metodo, o desenvolvedor nao precisa entender toda a logica interna.

  • Ao chamar list.sort(), voce nao precisa saber qual algoritmo e usado.
  • Ao usar uma API bancaria, voce nao ve como a transacao e processada internamente.

Beneficios da Abstracao

  • Reduz a complexidade do codigo para quem o utiliza.
  • Permite que equipes diferentes trabalhem em partes independentes do sistema.
  • Facilita a substituicao de implementacoes sem impactar outros modulos.
  • Torna o codigo mais legivel e organizado.
